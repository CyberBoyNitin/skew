Method

01
generate

A seeded grammar emits extraction probes around JSON edge cases, and custom probe files can add tool-use and safety cases.

02
sample

Every stack answers every probe N times at temperature 0. Calls are retried with backoff and bounded by a concurrency limit. The modal output and its stability are computed per stack.

03
classify

Stacks that disagree with themselves are marked unstable. The rest are compared structurally, with format-only, semantic, and safety verdicts.

04
minimize

Each divergence is delta-debugged over prompt segments and re-verified at the full trial count. Only reductions that reproduce the same disagreement are kept.

Limits

  • Stability is estimated from 3 trials. Temperature 0 reduces noise but does not remove it; stacks below the 0.8 threshold are reported as unstable, never as findings.
  • Minimization uses one trial per stack because the search is call-heavy. Every reduced prompt is re-checked at the full trial count; if it no longer reproduces, the original prompt is kept and the finding is marked unverified.
  • Prompts are minimized by removing whole segments (lines and blocks). The minimizer does not rewrite or paraphrase text.
  • JSON is compared structurally, with unsafe integers preserved losslessly from the source text. Prose is compared after whitespace normalization.
  • Native tool calls are normalized to {name, arguments}. Provider ids, envelopes, and serialization differences are ignored; tool choice and argument values are compared.
  • Stacks speak either OpenAI chat-completions or the Anthropic Messages API. Provider-specific sampling controls are not compared.
